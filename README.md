## Descripción

Desarrollo de cinco ejercicios en Java aplicando los conceptos fundamentales de la programación orientada a objetos (POO), mediante la creación de clases y objetos, el uso de atributos, constructores, métodos y estructuras de control.

| N.º | Ejercicio | Clases |
|-----|-----------|--------|
| 1 | Notas del curso | `Estudiante` |
| 2 | Inventario de una tienda | `Producto` |
| 3 | Veterinaria | `Mascota` |
| 4 | Cuenta de ahorro | `Cuenta` |
| 5 | Biblioteca | `Libro`, `Socio` |

## Herramientas utilizadas

- Java.
- Visual Studio Code o el entorno de desarrollo utilizado.
- Git y GitHub para el control de versiones y la publicación del proyecto.

## Instrucciones de ejecución

1. Clonar o descargar el repositorio.
2. Abrir el proyecto en el entorno de desarrollo.
3. Ingresar a la carpeta del ejercicio que se desea ejecutar.
4. Compilar y ejecutar la clase `Main.java` correspondiente, si existe.
5. Revisar los resultados mostrados en la consola.

**Nota:** La estructura y los nombres de los archivos deben coincidir con los que se encuentran realmente en el repositorio.

## Conclusión

El desarrollo de estos ejercicios permite comprender los fundamentos de la programación orientada a objetos en Java, fortaleciendo el uso de clases, objetos, atributos, constructores y métodos para representar situaciones de la vida cotidiana mediante programas.
